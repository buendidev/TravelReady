## 2. Estructura de colecciones

```
users/{uid}
  name, email, plan, planRenewalDate, createdAt, photoUrl

trips/{tripId}
  userId, name, destination, startDate, endDate
  transport[], tripType, activities[], progress, createdAt, notes

  packingLists/{listId}
    tripId, name, createdAt
    packingItems/{itemId}
      listId, tripId, name, category, isPacked,
      isAutoGenerated, quantity, order, notes

chats/{chatId}
  type (private|group), name, photoUrl, memberIds[],
  createdBy, createdAt, lastMessage, lastMessageAt, lastSenderId

  messages/{msgId}
    senderId, senderName, text, timestamp, readBy[]
```

**Nota**: listas standalone usan `userId` como `tripId` en la ruta.

## 3. Índices compuestos requeridos

```json
{
  "indexes": [
    {
      "collectionGroup": "trips",
      "fields": [
        {"fieldPath": "userId", "order": "ASCENDING"},
        {"fieldPath": "createdAt", "order": "DESCENDING"}
      ]
    },
    {
      "collectionGroup": "chats",
      "fields": [
        {"fieldPath": "memberIds", "arrayConfig": "CONTAINS"},
        {"fieldPath": "lastMessageAt", "order": "DESCENDING"}
      ]
    }
  ]
}
```

Deploy: `firebase deploy --only firestore:indexes`

## 5. Firebase Storage (fotos de perfil)

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /avatars/{userId}/{allPaths=**} {
      allow read: if request.auth != null;
      allow write: if request.auth != null
        && request.auth.uid == userId
        && request.resource.size < 5 * 1024 * 1024
        && request.resource.contentType.matches('image/.*');
    }
  }
}
```
